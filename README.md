# 🍅 PomoTimer — Modern Focus & Pomodoro Web App

A high-performance, distraction-free Pomodoro timer web application built with modern frosted glassmorphism, fluid gradient themes, Web Audio API sound synthesis, and local storage persistence.

![PomoTimer Logo](public/logo.png)

## ✨ Features

- **🎨 Modern Glassmorphism Aesthetic**: Translucent frosted cards, paper-cut perforated border accents, and fluid background transitions across Pomodoro, Short Break, and Long Break modes.
- **⏱️ Animated Circular Progress Ring**: Smooth SVG countdown meter synchronized with real-time browser tab title updates.
- **🔔 Web Audio Synthesizer**: Zero-latency offline sound alerts (Crystal Bell, Digital Chime, Zen Bowl, Kitchen Mechanical) with volume controls.
- **📋 Focus Checklist**: Minimalist to-do checklist with active task target binding, completion strike-through, reordering, and celebration confetti.
- **🧘 Fullscreen Zen Mode**: 1-click distraction-free overlay (<kbd>F</kbd>) for deep focus.
- **📊 Reports & Streaks**: Daily focus time tracking, consecutive day streaks, and 7-day activity visual chart (<kbd>R</kbd>).
- **🎨 Curated Theme Palettes**: Modern Sunset, Deep Aurora, Emerald Calm, and Obsidian Dark (<kbd>S</kbd>).
- **⌨️ Keyboard Shortcuts**:
  - <kbd>Space</kbd>: Start / Pause
  - <kbd>Alt</kbd> + <kbd>S</kbd>: Skip session
  - <kbd>F</kbd>: Fullscreen Zen Mode
  - <kbd>S</kbd>: Settings
  - <kbd>R</kbd>: Report & Analytics
  - <kbd>Esc</kbd>: Close modal / exit Zen mode

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/SpidyKingOp/pomotimer.git
   cd pomotimer
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
